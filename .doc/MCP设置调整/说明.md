# MCP 服务设置界面 · 设计文件

本目录存放「MCP 服务」设置弹窗的排版与样式优化设计成果。风格严格保持原截图的 Naive UI 绿色主题，仅调整排版、收敛冗余信息，面向桌面软件做到紧凑、扼要。

## 目录结构

```
.doc/
├── 说明.md                         本文件
├── html/
│   └── mcp-settings-redesign.html  可交互设计图，浏览器直接打开
├── md/
│   └── mcp-settings-redesign-prompt.md  可直接复制给 AI / 开发的改造说明
└── 图片/
    ├── mcp-settings-full.png       完整展开态设计图（990px 高）
    └── design-preview.png          默认视口渲染截图
```

## 文件用途

| 文件 | 用途 |
|---|---|
| `html/mcp-settings-redesign.html` | 高保真交互原型：开关、令牌生成/编辑/复制、JSON 折叠、tips 均可操作 |
| `md/mcp-settings-redesign-prompt.md` | 整份复制给 AI 即可执行，含风格基准表、6 项变更清单、目标结构、组件规格、可访问性与验收标准 |
| `图片/mcp-settings-full.png` | 完整展开态，一图看全全部字段与配置示例 |
| `图片/design-preview.png` | 默认视口下实际渲染效果 |

## 6 项调整摘要

1. 去除顶部「运行中」状态条。
2. 去除标题「MCP 服务」下方灰色副标题。
3. 「只读模式」「写操作确认」同行，说明文字改为 hover tips，删除常驻安全提示条。
4. 访问令牌改为可编辑输入框，新增「生成」「复制」按钮。
5. 去除「客户端连接」行（地址在 JSON 示例中已有）。
6. 「可用工具」与 127.0.0.1 监听说明上移到对应分组。

完整展开态高度由初版 2061px 收敛到 990px。
