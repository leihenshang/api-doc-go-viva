## 0. 任务目标

在**完全保留原截图视觉风格**的前提下，梳理「MCP 服务」设置弹窗的排版。**不增删业务字段、不改变后端逻辑、不改动文案含义**。

## 1. 风格基准（必须严格遵守，不得自行发挥）

这是典型的 **Naive UI 绿色主题**桌面端界面，所有视觉值以下表为准：

| 类别 | 值 | 说明 |
|---|---|---|
| 主题绿 | `#18a058` | 开关开启、复选框选中、主按钮、链接文字统一用它 |
| 主题绿 hover | `#36ad6a` | 主按钮 hover |
| 弹窗/控件背景 | `#ffffff` | 纯白扁平，无渐变、无毛玻璃 |
| 主文字 | `#333333` | 标题、正文 |
| 次要文字 | `#555555` | 标签、控件内文字 |
| 辅助文字 | `#999999` | 说明、占位符、工具列表 |
| 控件边框 | `#e0e0e6` | 输入框、次级按钮 |
| 分隔线 | `#f0f0f0` | 分组之间的细线 |
| 代码块背景 | `#f5f5f5` | JSON 区域，**不要语法高亮**，纯 `#333` 文字 |
| 字体 | 原系统字体（PingFang SC / Microsoft YaHei 等），正文 12px、辅助 11px | 不要换字体族 |
| 圆角 | 控件 3px、弹窗 4px、开关胶囊全圆角 | 小圆角，不要大圆角卡片 |

**禁止**：换深绿品牌色、加编号徽章、加网格舞台背景、加卡片阴影嵌套、加语法高亮、放大字号、加大留白。

## 4. 组件规格（保持原形态，仅统一尺寸）

| 组件 | 规格 |
|---|---|
| 开关 | 34×18px，关闭 `#d8d8de`、开启 `#18a058`，14px 白色滑块；`role="switch"` + `aria-checked` |
| 复选框 | 15×15px，边框 `#c8c8d0`、选中绿底白勾；原生 input 保留键盘可达 |
| 输入框 | 高 30px、圆角 3px、边框 `#e0e0e6`；focus 时绿边 + 2px 淡绿光圈；令牌输入框需可编辑 |
| Tips | 14px 圆形问号图标，灰边灰字；hover / `:focus-visible` 显示深色气泡，气泡朝下（避免被弹窗裁剪），文案取 `data-tip` |
| 按钮 | 主按钮「完成」`#18a058` 实底白字；次级白底描边（生成、复制、复制配置）；三级纯文字（清空/刷新/导出） |
| 代码块 | 浅灰 `#f5f5f5`、圆角 3px、等宽字体 11px、**无语法高亮**、最大高 190px 可滚 |
| 折叠块 | 原生 `<details>`，收起时仅一行小标题；展开后显示代码块和复制按钮 |

## 5. 交互

1. 切换两个权限开关时同步 `aria-checked` 与视觉状态（说明已进 tips，不再需要联动提示条）。
2. 令牌：输入框可手动编辑；点击「生成」生成新令牌回填并选中；点击「复制」复制输入框当前值。
3. JSON 默认折叠；展开后「复制配置」复制原始格式文本；复制后按钮短暂显示「已复制」。
4. 底部操作栏固定可见，中间内容区滚动。

## 6. 可访问性

- 正文对比度 ≥ 4.5:1；所有控件键盘可达，统一 `:focus-visible` 绿色焦点环。
- 开关 `role="switch"` 同步 `aria-checked`；关闭按钮有 `aria-label`；tips 图标带 `tabindex="0"` 与 `aria-label`，键盘可达。
- 尊重 `prefers-reduced-motion: reduce`。

## 7. 验收标准

1. 整体风格与原截图一致：绿 `#18a058`、白底、小圆角、紧凑。
2. 无「运行中」状态条、无标题下灰色副标题、无「客户端连接」行。
3. 「只读模式」「写操作确认」在同一行，说明为 hover tips 而非常驻文字。
4. 令牌为可编辑输入框，带「生成」「复制」按钮，复制取最新值。
5. 「可用工具」在工具权限分组内；127.0.0.1 说明在监听地址下方；底部「最近调用」无这两条。
6. 信息不丢失：原截图的全部字段、原文案含义、工作区、令牌值、JSON 示例、操作按钮均保留。
7. 控制台无报错。

## 8. 注意

- 「写操作确认」原文案"关掉后写工具直接执行，不再询问"**保持原样**放入 tips，不要改成正向表述。
- 令牌仅作用于展示层；手动编辑或生成后是否写回后端由业务决定。
- 若项目使用 Naive UI，直接复用其 `n-switch` / `n-checkbox` / `n-input` / `n-button` 默认主题，并按第 3 节重排结构、用 `n-tooltip` 承载说明文字。
