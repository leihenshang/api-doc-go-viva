# 快速开始

这份集合演示了客户端的各项能力：目录分组、请求参数、响应字段表与项目文档。

## 第一步：选择环境

顶部「环境」下拉切到 `dev`，`{{host}}` 与 `{{token}}` 会自动替换。

| 变量 | 说明 |
| --- | --- |
| host | 测试环境地址 |
| token | 访问令牌 |

## 第二步：发送请求

```bash
curl -X POST "$HOST/echo/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"alice","password":"s3cret"}'
```

- 响应会自动美化，可切「原始」看原文
- 字段表可以从响应一键生成

> 提示：Ctrl/⌘ + K 打开命令面板。
