# Viva 版 UI 复刻执行计划

对照物是 `screens/`（Wails 客户端 28 张浅色 + 5 张暗色截图）与 `metrics/`（每屏运行时度量）。
本文件只记录 **Viva 版** 的盘点、差距与批次；数值以 `metrics/*.json` 为准，截图用来看状态与层级。

> 2026-11-20 更新：T1–T4、T6–T8 已完成（状态行、截断提示、表格移行、请求历史、导入 / 运行器 / Mock / 代理证书、导出、行尾按钮闪烁）；
> T5 只补了 4 张截图，T3 的文档工具栏卡在 viva 的 `TextArea` 接口上。剩下的候选见 **§4 末尾「之后」**。

## 0. 约束

- 范围：桌面三平台；**同步 / 服务端绑定不在范围内**。MCP 已超出原计划实现（见 1.1），`18-settings-mcp`、`32-dark-settings-mcp` 从「只作参考」升为已对照。
- 组件：继续用 Viva 的 `ui` + `components`，不照搬 naive-ui 的 DOM 结构；观感对齐、不追像素级 diff。
- 数值口径：用 Wails 基准（13px / 侧栏 260 / 标题栏 44 / 页签 37 / 树行 30 / 控件 28 / 圆角 6），
  不采用 Flutter 端整体放大一档的数值。
- 本版是验证版：只实现能真实跑通的能力，参考图里有、但后端没有的动作宁可不放，也不放空按钮。

### 1.1 参考图之外已实现

- **顶栏融合**：`WindowCustomTitlebar` 无边框自绘标题栏——工具条就是标题栏，整行是拖动区，右端留给 viva 自绘的最小化 / 最大化 / 关闭，按钮配色跟主题走。
- **分栏 / 主题收成图标按钮**：描边分组 + 选中项主色浅底（浅 `#e8f5ee`、深 `#1b2b22`），不再显示「上下 / 左右 / 日间 / 夜间」文字。
- **地址栏「更多操作」**：保存 / 另存为、导入 cURL、导出 cURL、代码生成、格式化 URL。
- **响应正文框选 + `Ctrl/Cmd+C`**：JSON 与原始视图都支持，按真实字宽定位（中文双宽不偏）。
- **底部状态栏**：存储说明、回收站、MCP、当前集合的请求数与环境数。
- **内嵌 MCP 服务**（`internal/mcp`）：集合读写与真实发请求的工具，按集合根授权。
- **请求标题行**：接口概述回到标题下方，去掉了路径与分组展示。
- **网络设置**：代理地址与客户端证书（双向 TLS），和超时 / 重定向 / 忽略证书共用一份 Transport。
- **导入**：Postman v2 集合与另一个 OpenCollection 集合，可选落点分组，同名加 `-2`（T6）。
- **集合运行器**：勾选请求顺序跑，逐条状态 / 耗时 / 错误，支持失败即停与停止（T6）。
- **本地 Mock**：按集合里的请求假回复，响应体由字段表生成，`/__mock/routes` 列路由（T6）。
- **导出**：整集合导出 Markdown 或单文件 HTML（目录树 + 搜索 + 打印样式）（T7）。

### T8 修集合树行尾按钮闪烁 ✅

- 现象：指针移到请求行右端的「···」上，按钮反复出现 / 消失；顺带让名字的可用宽度一跳一跳。
- 根因：按钮原本「悬停才声明」——指针落到按钮上时 `Hovered()` 从行变成按钮，下一帧不声明，指针又落回行上。
- 修法：按钮一直声明（位置与命中稳定），可见性改由 `entryMenuVisible(行悬停, 按钮悬停, 菜单开着)` 决定，不显示时 `Opacity(0)`。
- 验收：`TestEntryMenuVisibility`（三种显示条件）+ `TestEntryMenuButtonStaysUnderPointer`（悬停行 → 移到按钮 → 按钮仍在 → 能开菜单）。
