# Viva 版 UI 复刻执行计划

对照物是 `screens/`（Wails 客户端 28 张浅色 + 5 张暗色截图）与 `metrics/`（每屏运行时度量）。
本文件只记录 **Viva 版** 的盘点、差距与批次；数值以 `metrics/*.json` 为准，截图用来看状态与层级。

## 0. 约束

- 范围：桌面三平台；**同步 / 服务端绑定 / MCP 不在范围内**（`18-settings-mcp`、`32-dark-settings-mcp` 只作参考）。
- 组件：继续用 Viva 的 `ui` + `components`，不照搬 naive-ui 的 DOM 结构；观感对齐、不追像素级 diff。
- 数值口径：用 Wails 基准（13px / 侧栏 260 / 标题栏 44 / 页签 37 / 树行 30 / 控件 28 / 圆角 6），
  不采用 Flutter 端整体放大一档的数值。
- 本版是验证版：只实现能真实跑通的能力，参考图里有、但后端没有的动作宁可不放，也不放空按钮。

## 2. 执行批次

### B1 视觉骨架（✅ 已完成）

- 令牌：`#f5f5f5` / `#ffffff` / `#e3e3e3`、选中 `#e8f0fe`（暗 `#16283d`）、悬停 `#ececec`。
- 尺寸：侧栏 260、标题栏 44、页签 37/12.5px、树行 30、控件圆角 6。
- 标题栏只放 `api-doc-go v0.1.0`；环境与请求页左边距对齐。
- ✅ 无集合启动：进入欢迎页点「打开集合」，Windows 双击 exe 不再直接退出；有上次集合则自动打开。

### B2 集合树（🟡 主体完成）

- ✅ 多根、嵌套分组、展开收起、搜索保留祖先、根行菜单、`seq` 排序。
- ✅ 缩进引导线：每行用零宽锚点自绘祖先列竖线。
- ✅ 行尾 hover「···」：悬停行显示入口，菜单与右键一致。
- ✅ 拖到分组 / 集合根完成跨目录移动（`ui.Tree.CanDrop` + `explorer.MoveEntry`）。
- ✅ 同级排序：拖到同目录条目的上 / 下缘，按完整同层顺序把 `seq` 重排为 1..N；请求只替换 `info.seq` 行，文档只换 frontmatter 的 `seq` 行，其余字节原样保留。
- ✅ 分组拖拽：拖到同父分组的上 / 下缘重排 `folder.yml` 的 `seq`；拖进另一个分组 / 集合根换父级，目录整体移动，打开中的标签路径跟着改前缀；不能移进自己或子孙。
- ✅ 悬停自动展开：拖拽停在折叠分组上 0.6 秒展开（`CanDrop` 记录悬停键与起始时间，下一帧在界面线程展开，定时器只负责唤醒）。
- ✅ 新建 / 重命名分组：根行菜单与分组右键；新建写最小 `folder.yml`（name / type / seq / uid），重命名只换 `info.name`，目录名不动。
- ✅ 克隆 / 删除分组：克隆深拷贝整棵子树，folder.yml 与请求 `meta.uid`、文档 uid 换新；删除整个目录进回收站，回收站可恢复（回集合根）。
- ✅ 跨集合移动：条目 / 分组拖到另一个集合根；条目同名补 `-2`，分组同名按客户端语义拒绝；移动后两个根各自重扫，源根的标签自动关闭。
- ✅ 树键按「集合根 + 相对路径」区分：两个集合有同名分组 / 条目同时展开时不会撞键（Viva Tree 的键必须唯一，否则 panic）。
- ✅ 工具条集合切换下拉：列出已打开的根并标记当前根，可「打开集合…」或「关闭当前集合」；重名集合补目录名尾巴。

## 3. 每批的验收

1. `bash scripts/check.sh` 与 `go test -race ./...` 全绿。
2. 新增交互必须有 `view_test.go` 的无头驱动用例（点标签/点按钮 → 断言模型与画面文字）。
3. 与 `screens/light/<编号>.png` 同状态截一张图，放 `doc/`，并在主 README 引用。
4. 不引入新的每帧分配：派生数据在状态变化时算一次（遵循 `building-with-viva` skill）。

## 4. 建议顺序

1. B5 收尾：大响应截断提示（现在 1 MB 上限无提示）。

4. B9 收尾：代理 / 客户端证书、label 90px 右对齐。
5. B11 命令面板：请求 / 环境分组与快捷键右对齐。
