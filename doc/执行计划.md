# Viva 版 UI 复刻执行计划

对照 `screens/`（Wails 客户端 28 张浅色 + 5 张暗色截图）与 `metrics/`（每屏度量）。
本文件只记录 **Viva 版**的盘点、差距与待办；数值以 `metrics/*.json` 为准，观感看截图。

> 2026-11-20 重写：已完成的批次收进 §2、§3 各一行，不再逐条留历史。
> **接下来做什么已搬到 [`doc/任务清单.md`](../doc/任务清单.md)**（含与 Wails 版的功能对比），本文件只保留盘点与验收口径。

## 0. 约束

- 范围：桌面三平台；**同步 / 服务端绑定不在范围内**。MCP 已超出原计划实现（§3）。
- 组件：继续用 Viva 的 `ui` + `components`，不照搬 naive-ui 的 DOM；观感对齐，不追像素级 diff。
- 数值口径用 Wails 基准：13px / 侧栏 260 / 标题栏 44 / 页签 37 / 树行 30 / 控件 28 / 圆角 6。
- 只实现能真实跑通的能力：参考图里有、后端没有的动作宁可不放，也不放空按钮。

## 2. 参考图之外已实现

- **顶栏融合**：`WindowCustomTitlebar` 无边框自绘标题栏，工具条即标题栏（整行拖动区 + 自绘窗口三键，配色跟主题）。
- **图标按钮**：分栏方向做成描边分段控件（选中项主色浅底 `#e8f5ee` / `#1b2b22`），主题只留图标。
- **响应正文框选 + `Ctrl/Cmd+C`**：按真实字宽定位，中文双宽不偏。
- **底部状态栏**：存储说明、历史、Mock（带状态点）、回收站、MCP、集合规模。
- **内嵌 MCP 服务**：集合读写与真实发请求的工具，按集合根授权，默认端口 2026。
- **请求标题行**：概述回到标题下方，去掉路径与分组。
- **集合运行器 / 本地 Mock / 导入 / 导出 / 请求历史**：见 §3 的 T4·T6·T7。
