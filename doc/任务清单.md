## 三、有问题 / 已知限制

1. **MCP 面板内容仍偏长**：「最近调用」在滚动区末尾，要滚到底才看全。试过改成原生 Tabs 分页
   （每节一页、弹窗 470 高），效果不错但不符合「分节长页」的预期，已回滚。
2. **MCP 审计是打开时的快照**：面板开着时 AI 继续调用不会自动刷新，要手动点「刷新」。
3. **参数不合法的调用不进审计**：schema 校验在 SDK 层就被拦下，工具没执行、界面上也看不到这次失败。
   属预期行为，但排查时容易误以为「没调用」。
4. **请求栏标签是自绘 + 借用原生视觉**：viva 的 `ui.Tabs` 不支持关闭按钮、拖拽排序、横向滚动、
   溢出菜单，直接换组件会丢功能。Line 风格下选中与未选中的差别只剩「绿线 + 加粗」，比原来的白底块安静
   —— 觉得对比不够可以回退到卡片底。
5. **变量悬停两条坐标边界**（机制已解决，见 `view/varhover.go`）：折行的 `ui.TextArea` 只有整框提示；
   聚焦且超宽的单行输入框不弹提示（平台横向滚动、canvas 文本原点不动）。
6. **`.doc/MCP设置调整/` 设计稿已随代码入库**（HTML + 图片 + 说明约 150KB）。不想入库的话需移出并加 `.gitignore`。
